# User avatars: bear, lion, dragon

Monie is the chat guide; users get one of these animals instead. The love quiz picks the animal and the career quiz picks the job.

- `<animal>/full/<job>.svg`: full-body character (viewBox 0 -24 240 220), transparent background.
- `<animal>/circle/<job>.svg`: circle avatar (neon circle, cobalt ring); the sticker shadow is added in CSS so it can switch with light and dark mode.
- `base-A/B/C.svg`: the animal with no job, in the friendly, cheeky and content faces (used on the love quiz animal picker).
- Job file names match `images/monie-work/` groups: `tech-developer`, `hospitality-chef`, `safety-firefighter`, and so on (64 jobs).

Design reference: the "User avatars: bear, lion, dragon" page on the Monie canvas.
